## ⚙️ なぜマグネシウムか－密度 1.74 g/cm³ の軽量化

マグネシウムは密度 **1.74 g/cm³** で、アルミニウムより約 **33 % 軽く**、鋼より約 75 % 軽いです。そのため重量が決め手となる場面では、マグネシウム高圧ダイカスト（HPDC）が首选の工法となります。[電気自動車（EV）](https://alumcasting.com/ev-battery-housing-die-casting/)や電子機器筐体、産業部品まで幅広く使用されています。

[マグネシウムとアルミニウムのダイカスト比較](https://alumcasting.com/magnesium-vs-aluminum-die-casting/)で、多くのお客様が選ぶ[材料変更による軽量化](https://alumcasting.com/aluminum-to-magnesium-conversion-weight-reduction/)をご確認ください。

![マグネシウムダイカスト生産ライン](/img/magnesium-die-casting-banner.webp)

### 🔬 マグネシウム合金－AZ91D と AM60B

当社は実績のある 2 合金を主に鋳造します。

* **[AZ91D](https://alumcasting.com/az91d-magnesium-die-casting-automotive-parts/):** 高強度かつ優れた耐食性－電子筐体や薄肉構造に最適。
* **[AM60B](https://alumcasting.com/am60b-magnesium-alloy-die-casting-suppliers/):** 延性と衝撃強度に優れ－自動車安全部品に好適。
* **AM50A / その他合金:** プロジェクト固有の要求に応じて対応。

| 合金 | 密度 (g/cm³) | 強度 | 延性 | 主な用途 |
| :--- | :--- | :--- | :--- | :--- |
| **AZ91D** | 約1.81 | 高 | 中 | 筐体、電子、構造 |
| **AM60B** | 約1.79 | 中 | 高 | 安全部品 |
| **AM50A** | 約1.77 | 低 | 極高 | 大型部品（要相談） |

## 🏭 HPDC 工程と設備（400T～3000T）

当社工場は **400T～3000T の HPDC ライン** を備え、後加工用に高精度 CNC 工場を併設しています。マグネシウムの溶解・保持は **保護ガス雰囲気**（SF₆ フリー混合ガス）下で行い、酸化と発火リスクを最小化します。完全な[製造能力](https://alumcasting.com/manufacturing-capabilities/)には、見積段階からの流動解析・DFM が含まれます。

![自動化ダイカスト生産ライン](/img/automated-die-casting-production-line.webp)

| 項目 | 仕様 |
| :--- | :--- |
| **型締力範囲** | 400 トン ～ 3000 トン |
| **肉厚** | 最小 1.0 mm ～ 1.2 mm |
| **直線公差** | CNC 後加工で ±0.01 mm |
| **表面仕上** | [MAO 皮膜](https://alumcasting.com/magnesium-die-casting-corrosion-protection-mao-coating/)、E-Coating |

## 🧯 設計の留意点－安全と腐食

マグネシウムには固有の設計ルールがあります。以下を支援します。

1. **防火・取扱:** 密閉保護ガスシステム、自動真空充填、安全な溶解プロセス。
2. **薄肉化:** 1.0 mm からの肉厚を実現。フライス領域と補強を金型段階で計画。
3. **防食:** [MAO 皮膜](https://alumcasting.com/magnesium-die-casting-corrosion-protection-mao-coating/)と E-Coating に加え、接触腐食を防ぐ設計手段。

## ⚖️ マグネシウム vs. アルミニウム－重量

| 特徴 | マグネシウム (AZ91D) | アルミニウム (例: A356) |
| :--- | :--- | :--- |
| **密度** | 約1.81 g/cm³ | 約2.68 g/cm³ |
| **体積あたり重量** | 約33 % 軽い | 基準 |
| **減衰性** | 極めて良い | 良い |
| **防食** | MAO/E-Coating | 陽極酸化/粉体 |
