## Linking Rule

Each technical article should link to one primary commercial page and one RFQ/contact path. Links should answer the next engineering or purchasing question rather than repeat the same anchor text.

## Content Guardrails

- No new pages for unsupported machine ranges, A357 production, zero-defect, universal tolerance or guaranteed lead-time claims.
- No low-value translation of every article into all seven languages.
- Use primary technical sources for alloy, inspection and process claims.
- Keep one search intent per URL and preserve existing slugs.
