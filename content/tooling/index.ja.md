## 高精度ダイカスト金型製作

ダイカスト金型は単なる「型」ではない。それは充填挙動、気孔の発生、寸法精度、そして製品ライフサイクル全体にわたる部品原価を決定する核心部品である。Kingshipはアルミニウムおよびマグネシウムの構造部品鋳造向けに、**DFMに基づく金型設計、金型流動解析、CNC／EDMで加工したキャビティ、および資格認定を経たT0／T1サンプル**を提供する。初品評価から量産保守まで一貫して対応する。

本ページでは、ダイカスト金型がいかに設計・解析・製作・検証されるか、どの鋼種と表面処理が用いられるか、品質をいかに確保するか、そして信頼できる金型見積依頼に必要な情報を解説する。

### ダイカスト金型と樹脂射出成形金型

金型選定は、そもそも部品がどのプロセスファミリーで製造可能かという問いから始まる。以下の比較は一般的な設計上の指針であり、正確な仕様はDFMにおいて確認される。

| 項目 | ダイカスト金型 | 樹脂射出成形金型 |
| --- | --- | --- |
| 金型材料 | H13 / SKD61 熱間工具鋼 | P20 / 718（調質鋼） |
| 使用温度 | 約600〜700℃の溶湯、熱サイクル負荷 | 約200〜300℃、より緩やかな熱履歴 |
| 相対的工数 | 樹脂金型の約2〜4倍 | 基準 |
| 典型寿命（Al） | 100k〜500kショット（業界標準） | 樹脂ではより長いが別プロセス |
| 主な摩耗 | キャビテーション・熱・溶損 | 摩耗、薬品耐性 |
| 最適用途 | 金属鋳物、構造部品 | 樹脂部品、絶縁部品 |

### 金型設計・DFM

優れた金型はフライス盤の前ではなく、設計段階で生まれる。本プロセスの**DFM（Design for Manufacturability＝製造性設計）**段階では、図面と部品形状を「鋳造に適した設計」として評価し、鋼を切削する前に問題を顕在化させる。

| DFM確認項目 | 評価内容 | 典型目標 / 課題 |
| --- | --- | --- |
| 最小肉厚 | 流動長 vs 肉厚断面 | 薄すぎ→湯回り不良、充填不可 |
| 肉厚遷移 | 急な厚→薄の変化 | 引け巣、反り |
| ゲート・押湯 | ゲート位置、後補給 | コールドショット、巻き込み回避 |
| エアベント | ベント溝、ガス経路 | 緻密部のガス巣 |
| 冷却 | 冷却水路配置 | 熱バランス、サイクルタイム |
| 抜き勾配 | 各面の最小勾配 | 焼付き、押出し損傷 |
| R・面取り | エッジ半径 | 応力集中、割れ |
| キャビティ数 | 1〜8（生産量依存） | 経済性 vs 金型寸法 |

### ゲート・ベント・冷却戦略

充填、ガス抜き、冷却は互いに強く結びついた三つの設計変数である。適切に配置されたゲートは層流で充填し、巻き込み（空気・スラグ）を抑制する。分割面やコアに設けたベント溝は、閉じ込められたガスに制御された逃げ経路を与える。同時に**冷却水路の配置**が金型の熱バランスを決定する。過熱は充填を容易にするがサイクルタイムが伸び反りが増大し、過冷は湯回り不良のリスクを招く。ゲートと冷却はプロジェクトごとに設計し、双方を金型流動解析によって検証する。

### 金型流動・凝固解析

最初の刃物が入る前に、充填・凝固・熱力学的挙動をシミュレーションする。MagmaやMoldflowといった手法は、プロジェクトごとに活用可能な解析手段として、ガス残り・湯回り不良・巣・反りを早期に検出するために用いる。解析は完成した鋼に対する高価な手直しのリスクを低減する*開発支援ツール*であり、結果を一律に保証するものではない。

### 金型用鋼・材料（H13 / SKD61）

鋼種選定は寿命と部品品質を左右する。熱疲労やキャビテーションに耐える熱間工具鋼を優先的に採用する。

| 鋼種 | 分類 | 典型硬度 | ダイカスト用途 |
| --- | --- | --- | --- |
| **H13 (1.2344)** | 熱間工具鋼 | 42–50 HRC | 標準キャビティ・コア、Al/Mg |
| **SKD61** | H13相当（日本規格） | 44–50 HRC | 高品質キャビティ、精密部品 |
| **H11 (1.2343)** | 熱間工具鋼（低C） | 40–48 HRC | 靭性部品、高ショック負荷 |

窒化やCrNコーティングといった表面処理は耐摩耗性と離型性を高める。鋼種・硬度・コーティングの具体的な組合せは、部品要件に応じてプロジェクトごとに決定される。これらは金型資格認定の出発点であり、一律に保証される性質のものではない。

### CNC・EDM・金型加工

キャビティは素材から削り出す。高速フライスで粗加工から仕上げ形状を生成し、EDM（放電加工）で輪郭を持つ、あるいはアクセス困難なキャビティ部位を精密に加工する。専用の金型流動解析用ワークステーションで、切削前に金型を仮想的に試験する。厳しい寸法関連を要する特徴は切削による後加工で仕上げられ、そこでは加工後の公差として**±0.01 mm**の範囲が達成可能である——これは鋳造公差ではなく、形状とプロジェクトごとに確認される加工後条件である。

### 金型組立・試運転

個別部品の加工後、キャビティ・コア・スライド・エジェクタ・冷却系統を嵌合精度よく組み立てる。初ショット前に事前調整と嵌合検査を行い、サイクルに入る前に組立不良を検出する。

### T0/T1サンプル・検証

金型は段階を経て資格認定される。**T0**は充填性と抜け性の大まかな評価のための最初の物理部品をもたらし、**T1**（および以降の段階）は図面に対する寸法・気孔の検証に供される。初品検査と、プロジェクトごとの文書（顧客プログラムが求める場合のPPAP等）がこのプロセスを伴走する。

### 寸法検査・品質管理

金型品質はプログラムごとに設定される。典型的には**プロジェクトごと**に採用される検査手法には以下が含まれる。

- **CMM寸法検査** — 初品および工程付随の寸法管理。
- **X線気孔検査** — 受入基準に対する定性的／定量的な気孔評価。
- **材料証明** — 合金組成および熱処理データ（依頼ごと）。
- **PPAP／承認文書** — 顧客プログラムが求める場合に用意される。

Kingshipの品質マネジメントシステムの方向性（例：IATF 16949／ISO 9001の要件への準拠）は、プロジェクトの資格認定時に確認される。特定プログラムにおける認証ステータスはこの段階で明らかにされる。われわれは一律の「気孔ゼロ」や「欠陥皆無」を主張することは**ない**——品質は部品ごとに検証される。

### 寿命・保守・生産準備

アルミ金型における**100,000〜500,000ショット**の典型的寿命は業界の標準的範囲であるが、プロジェクト依存である。合金・肉厚・ゲート・保全が実際の数値を決定する。量産での可用性を高めるため、**予防保全、交換用インサート、および再生（リコンディショニング）**を支援する。磨耗部品はプロジェクトごとに手配される。

### 二次加工

金型は多くの場合、取り扱いとリードタイムを削減するために鋳造プログラムと組み合わせて提供される。

- **CNC加工** — 加工後の公差は±0.01 mmまで達成可能、形状ごとに確認。
- **ブラスト処理** — 表面準備と外観仕上げ。
- **アルマイト／コーティング** — 耐食性と外観。
- **組立** — サブアッセンブリとハードウェア組込み（依頼に応じ）。
